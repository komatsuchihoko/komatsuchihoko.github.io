Privacy Policy

Last updated: June 12, 2026

Overview

Nekohita Uploader is a personal tool used solely by its developer to upload guitar performance videos to Instagram, Threads, and YouTube. This app is not distributed to the public and is used only by a single user (the developer).

Data Collection

This application does not collect, store, or share any personal data from third parties. The only data handled is the developer's own access tokens, which are stored locally on the developer's personal computer and are never transmitted to any third-party server.

Use of Instagram and Threads API

This app uses the Instagram Graph API and Threads API solely to publish video content to the developer's own Instagram and Threads accounts. No data from these platforms is collected, stored, or shared with any third party.
